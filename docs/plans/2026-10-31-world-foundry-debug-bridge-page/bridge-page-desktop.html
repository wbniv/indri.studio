The debug bridge, up close

A running World Foundry engine can be inspected and driven from outside, one line of JSON at a time. These are the ways to look at it: tools that connect to it, and what comes back.

Blender live panel

Captured from a live engine

Blender connected to a running game. Connection status, the engine's CPU time and actor count, Pause and Pick Object, and the mailbox watch list.

The editor

Existing screenshot

The in-engine editor, with outliner, live viewport and properties. It reaches the engine through its own in-process bridge rather than this TCP one, so it sits beside the debug bridge.

A terminal session

Captured from a live engine

Ping, pause, step, watch a mailbox, write one, take a screenshot, resume. Lines starting with > are sent; < are replies.
